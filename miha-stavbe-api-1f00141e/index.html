1. Palisada - parkirni sistem

API DA - prek integracij (B2B)

Gre za palisada-sistemi.si (slovensko podjetje, parkirni sistemi + „Nadzorni center" spletna aplikacija). Sistem je modularen in izrecno predviden za povezavo z zunanjimi aplikacijami:

  • Posredovanje stanja zasedenosti parkirišča mobilnim parkirnim aplikacijam prek vmesnika.
  • Povezava prek API na NCUP (nacionalni center) - daljinsko upravljanje zapornic, sprememba zasedenosti, semaforji.
  • Povezava z redarsko aplikacijo in plačilnimi sistemi prek vmesnikov.

Ni pa javnega razvijalskega portala / odprte dokumentacije - to je integracija „na dogovor".

Rabim od Mihe: kateri Palisada moduli so v uporabi + dovoljenje, da vprašam Palisado za API specifikacijo (kontakt: info@palisada-sistemi.si).

2. „Ofis" = Spacebring (najverjetneje)

API DA - moderni, najmočnejši od treh

„Space brink" se ujema s Spacebring (prej andcards; SaaS za upravljanje pisarn/coworkinga, Gdansk). „Ofis" je zelo verjetno njihova prevedena/white-label različica. To moram potrditi z Miho.

  • Javni REST API (HTTPS), zgrajen po REST načelih; dokumentacija + OpenAPI spec na GitHubu.
  • Webhooki (dogodki v realnem času) - npr. rezervacije, člani, računi.
  • Predvidene integracije: CRM, sistemi za dostop/kontrolo vrat, lasten tech-stack.
  • Ima celo odprt MCP strežnik (v imeniku konektorjev Clauda in ChatGPT) - za hitre poizvedbe brez pisanja kode.
  • Komercialno: API & webhooki so plačljiv add-on na Spacebring naročnino.
Rabim od Mihe: potrditev, da je „Ofis" res Spacebring + admin dostop do računa in kaj točno želijo povezati (npr. parkirišče ↔ pisarne ↔ domofon ↔ računovodstvo).

3. BTicino domofoni + ideja večjezičnega ogovarjanja

API DELNO - lokalno (OpenWebNet) + SIP; cloud v prehodu

BTicino (skupina Legrand). Integracijske poti:

  • OpenWebNet - njihov lokalni protokol (od 2000). Podpira razrede za domofone in videodomofone (odpiranje vrat, kamera, dogodki klica). Dostop prek IP prehoda (npr. F454); obstaja veliko odprtokodnih integracij (Home Assistant, openHAB) - dokaz, da je tehnično odprto.
  • SIP - IP domofoni (npr. Classe 300X/100X) delujejo po SIP; nanje je mogoče priklopiti lasten SIP odjemalec/softphone.
  • Cloud / uradni Legrand developer SDK - obstaja, a je „DoorEntry SDK" ukinjen in se seli na Netatmo arhitekturo → trenutno zanesljiva pot je lokalno (OpenWebNet/SIP), ne cloud.

Glede večjezičnega ogovarjanja obiskovalca:

  • BTicino Sfera panel že ima večjezično govorno sintezo - a le za statusna sporočila (odpiranje vrat, klic posredovan, zasedeno), nastavljivo prek TiSferaDesign. Ni pogovor z obiskovalcem.
  • „Moderno, da ogovorimo obiskovalca v več jezikih" (koncierge/IVR) ni vgrajena funkcija - izvedljivo je kot nadgradnja prek integracije: panel/IP sistem kot SIP točka → lasten sistem z večjezičnim TTS (meni jezikov ali avtodetekcija), ali prek OpenWebNet prožimo lasten avdio ob dogodku klica.
  • Izvedljivost + cena močno odvisni od obstoječe strojne opreme.
Rabim od Mihe (ključno): katera BTicino oprema je nameščena - 2-žični (Sfera/Linea panel + Classe monitorji) ali IP sistem? Je prisoten prehod F454? Uporabljajo cloud/aplikacijo (Netatmo)? Od tega je odvisno, ali gre večjezični koncierge sploh in po kateri poti.

Zaključek + naslednji korak

Vse tri imajo neko obliko dostopa: Spacebring je najbolj „developer-friendly" (javni REST + webhooki + MCP), Palisada ima B2B integracije na dogovor, BTicino je odprt lokalno (OpenWebNet/SIP), cloud pa je v prehodu. Večjezično ogovarjanje je izvedljivo, a kot custom nadgradnja, ne „iz škatle".

Ko mi poveš več o Mihi in ciljih, lahko naredim konkreten predlog arhitekture (kaj povezati s čim) + oceno obsega.
